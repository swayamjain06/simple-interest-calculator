# Contributor Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful, welcoming, and harassment-free experience for everyone. This applies regardless of age, disability, ethnicity, gender identity or expression, nationality, race, religion, sexual orientation, experience, or background.

## Our Standards

- Welcome new contributors and respect different perspectives.
- Give specific, constructive feedback and accept feedback in good faith.
- Take responsibility for mistakes and work to repair harm.
- Keep discussions relevant and respect personal boundaries.

Harassment, discriminatory remarks, personal attacks, threats, unwanted sexual attention, and sharing someone else's private information without permission are unacceptable.

## Enforcement Responsibilities

Project maintainers are responsible for applying these standards fairly. They may edit or remove content that violates this code and restrict participation when necessary. A maintainer involved in a report should step aside from reviewing it.

## Scope

This code applies in the project's issues, pull requests, discussions, and other project spaces. It also applies when someone officially represents the project in public.

## Enforcement

For behavior on GitHub, use GitHub's [abuse reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies#reporting-abuse). You can also contact a project maintainer privately through any contact method they list on their GitHub profile. Include a link and a brief description if you can do so safely. Keep sensitive details out of public issues. Maintainers will review reports they receive promptly and share identifying details only as needed to respond.

## Enforcement Guidelines

Maintainers consider the impact, severity, and frequency of the behavior when choosing a response.

1. **Correction.** Explain the violation privately and request a specific change.
2. **Warning.** Issue a formal warning and set clear limits on further interaction.
3. **Temporary ban.** Suspend participation for a defined period for serious or repeated violations.
4. **Permanent ban.** End participation for severe violations or a continued pattern of harmful behavior.
